# Coin masking

## Preparation
a black background
a yellow circle (coin)

### 1. Coin not present
when the coin is not deteced, it will be in red word "coin not present"

### 2. Coin present
when the coin is deteced, it will be in green word "coin present"

### 3. Hand detected
when hand is detected, it will only show in red work "hand detected"
